🔍 2 Minor Refinements for Your Notes


1. The Word "Amortized" vs. "Average"

• What you wrote: "O(1) ie amortized constant time (where amortized means average time)"
• The Tech Review: In computer science, Amortized time and Average time have slightly different meanings:
	• Average Time: Means if you run an operation 1,000 times, most of the time it takes \(O(1)\), but occasionally it might take longer due to unpredictable data distribution (like a hash collision).
	• Amortized Time: This term is specifically used for Dynamic Arrays. When you add an item to a dynamic array, it usually takes \(O(1)\). But when the array gets completely full, Python has to secretly create a brand-new, double-sized array in memory and copy all old items into it—which takes \(O(N)\) time. Because this heavy \(O(N)\) copy operation happens so rarely, its high cost is "spread out" over thousands of cheap \(O(1)\) operations. That "spreading out" is what amortized means.
• Correction for your notes: For Hash Tables, say "O(1) average time complexity."

2. The Index Math & The Modulo Operator (%)

• What you wrote: "Which u can further divide 30/10 = 3"
• The Tech Review: If your array has a fixed size of 10 slots (indices 0 to 9), you don't use standard division, because a large string might add up to 95, and \(95 / 10 = 9.5\) (which isn't a whole index).
• The Fix: Real hash functions always use the Modulo Operator (%), which gives you the remainder of a division.
	• \(30 \pmod{10} = 0\) (Remainder is 0 \(\rightarrow \) Index 0)
	• If the sum was 33: \(33 \pmod{10} = 3\) (Remainder is 3 \(\rightarrow \) Index 3)
• The modulo operator acts as a reliable mathematical guardrail that forces any large number to land safely between 0 and your maximum array size minus one.

💥 What happens if a collision occurs?

What if you have another name, like "gerg"? It contains the exact same letters, so its sum is also 37. \(37 \pmod{10} = 7\). Both "greg" and "gerg" want to sit in Index 7.
This is called a Hash Collision. As you correctly noted in point #1, we solve this by making Index 7 point to a Linked List of nodes. Index 7 will simply hold a pointer to a chain: ["greg"] -> ["gerg"].
